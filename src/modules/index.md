# Modules Index

Reusable Node scripts shipped with vibegame. Each module is loadable directly from scene JSON via `script: "<Name>Module"` (see [`spec/engine/modules.md`](../.vibegame/spec/engine/modules.md) for the routing rule), or subclassable from `scripts/`.

One line description + one line interface per module. For full docs, open the matching `spec/contracts/<topic>.md` (when one exists) or read the module's source header.

## Catalog

- `StatusBarModule` — Sprite-backed status bar (HP / mana / stamina / shield / boss posture); pairs with [`spec/contracts/status_bar.md`](../.vibegame/spec/contracts/status_bar.md) Pattern `sprite-backed-status-bar`.
  - `config: { icon?, slot, bar, bbox: {x,y,w,h}, x?, y?, scale?, depth?, iconGap?, leftRate?, scrollFactor?, slotSize?: {width,height}, label?: {text,...} }`; method `setLeftRate(value)` (0–1, clips bar from the right).
- `MaskHUDModule` — Discrete N-pip icon meter (player HP as mask / heart icons); pairs with [`spec/contracts/status_bar.md`](../.vibegame/spec/contracts/status_bar.md) Pattern `discrete-icon-meter`.
  - `config: { iconKey, slotCount?, size?, gap?, anchorX?, anchorY?, depth?, dimAlpha? }`; method `setValue(n)` (0..slotCount, dims trailing icons).
- `GameOverlayModule` — DOM-based pause / death / victory / custom menu overlay with correct Phaser-scene pause integration; pairs with [`spec/contracts/game_overlay.md`](../.vibegame/spec/contracts/game_overlay.md) Pattern `dom-overlay-with-phaser-pause`.
  - `config: { menus: [{ id, title?, subtitle?, pausesGame?, toggleKey?, buttons: [{ label, action }] }], style?: { panelTexture?, buttonIdleTex?, buttonHoverTex?, fontFamily?, titleColor?, subtitleColor?, panelWidth?, panelHeight?, containerId?, hurtFlashColor? } }`; methods `showMenu(id)`, `hideMenu(id?)`, `isMenuVisible(id)`, `flashHurt()`.
- `MagnetOrbModule` — Collectible orb that accelerates toward a target tag after entering a magnet range. Verified for roguelike dungeon reward pickups. Pickup detection is the caller's job: overlap-watch the pickup tag, grant `orb.value`, then `orb.destroy()`.
  - `config: { visual: { type: 'circle'|'image', ... }, value?, pickupTag?, targetTag?, magnetRange?, maxSpeed?, acceleration?, depth?, x?, y? }`; property `this.value`; method `destroy()`.
- `MinimapModule` — DOM grid minimap for a roguelike dungeon layout; auto-draws orthogonal room connections, exposes per-room state (hidden / adjacent / explored / current) + roles (start / boss) via CSS classes.
  - `config: { mountSelector, assetUrlForKey, assetKeys?, style?: { roomW, roomH, gapX, gapY, padding }, elementId?, className? }`; methods `setRoomData(roomData)`, `setCurrentRoom(currentIdx, exploredSet)`.
- `UpgradeChoiceModule` — DOM 3-of-N upgrade/buff choice overlay with category-banded cards (offense/defense/utility), keyboard 1..N or click selection, animated entry. Verified for roguelike dungeon reward choices after a room is cleared.
  - `config: { buffPool: [{ id, label, desc, category, icon }], onSelect(buff), onClose?, choiceCount?, mountSelector, strings? }`; methods `show()`, `hide()`, `isVisible()`.
- `DomCardManagerModule` — DOM/CSS hand frontend for card games: renders pure card data into flat or arc hands, handles hover lift, drag-to-target play, target highlight, atlas-clipped card art, tooltip, and chevron drag arrow; pairs with [`spec/contracts/dom_card.md`](../.vibegame/spec/contracts/dom_card.md) Pattern `dom-card-hand-frontend`.
  - `config: { cardAtlas?, logicalWidth?, logicalHeight?, scaleMode?, layout?, cardW?, cardH?, xSpread?, handRootW?, handRootH?, arcCenterX?, arcCenterY?, arcRadius?, arcCenterAngleDeg?, arcAngleStepDeg?, arcMaxAngleDeg?, hoverScale?, hoverLift?, neighborShift?, hitboxPad?, snapBackDuration?, arrowColor?, arrowChevronSpacing?, arrowChevronLength?, arrowChevronWidth?, arrowChevronStroke?, arrowSpring?, enemyTargetEffects?, targets? }`; methods `setState({ cards, energy, phase, locked })`, `refresh(cards, energyOrState, phase?, locked?)`, `setCardPlayCallback(fn)`; emits `card_play_requested`.
- `SwipeSlashModule` — Pointer-swipe slash: glowing vector trail + continuous segment-circle hit detection against tagged targets, per-swipe dedup + combo counts; routes each hit to the target's own method and calls optional host hooks.
  - `config: { hostTag?, minDistance?, hitPadding?, trailMs?, depth?, glowColor?, glowWidth?, glowAlpha?, coreColor?, coreWidth?, coreAlpha?, groups: [{ tag, method, category?, defaultRadius?, stopOnHit? }] }`; host hooks `canSlash()`, `onSwipePointerDown(point)`, `onSwipeStart(slash)`, `onSwipeHit(info)`, `onSwipeEnd(slash)`; method `activeSlashSummary()`.
- `TimedImageVfxModule` — Fire-and-forget transient sprite effect: spawn at a position, then auto moves / spins / scales / fades with optional texture sequence over `ttl` before removing itself.
  - `config: { texture?, textureSequence?: [{ texture, at }], ttl?, width?, height?, velocityX?, velocityY?, spin?, alphaStart?, alphaEnd?, scaleStart?, scaleEnd?, depth?, angle?, rotation?, flipX?, flipY?, kind?, label? }`; method `runtimeState()`.
- `SideviewFighterModule` — Input-driven sideview combat controller: Animator state machine + AnimationPlayer + Collider hitbox management. Handles walk/run/jump/dash/guard/defense_walk/attack(combo)/deflect/deathblow. All behavior configured via `config` + `animator` in node.json, zero game-specific logic.
  - `config: { moveSpeed?, runSpeed?, guardSpeed?, jumpForce?, dashSpeed?, dashDuration?, comboWindowRatio?, deflectWindowMs?, attacks?: { [state]: { hitbox, activeFrames } }, deathblowSheatheDuration?, deathblowIaiDuration?, deathblowThroughDuration?, deathblowTeleportOffset?, deathblowArriveFinishDuration?, afterimageCount?, afterimageFadeDuration?, deathblowWindowDuration? }`; methods `enableDeathblow(target)`, `disableDeathblow()`, `tryDeflect()`; properties `facing`, `_dashTimer`, `_dashDir`.
- `ParallaxModule` — One scrolling parallax background layer (TileSprite + scrollFactor + depth + optional self-drift); stack sibling nodes for sky/far/near depth. No collision/state. Pairs with [`spec/contracts/parallax_background.md`](../.vibegame/spec/contracts/parallax_background.md) Pattern `scrolling-parallax-layers`.
  - `config: { texture, frame?, x?, y?, width?, height?, originX?, originY?, scrollFactorX?, scrollFactorY?, depth?, driftX? }`; method `runtimeState()`.
